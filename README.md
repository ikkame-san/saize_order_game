# サイゼ注文ゲーム

同じ卓の友達の注文を、4桁の番号で入力する非公式ファンゲームです。
PC・スマホ対応。インストールやビルドは不要です。

## 遊ぶ

`index.html` をブラウザで開き、パッドの外の「ゲームをはじめる」を押します。

- **60秒間に正しく注文できた品数**を競います。
- 連続正解すると、1コンボ目は0.1秒、2コンボ目は0.2秒のように残り時間が増えます。10コンボ目以降は毎回1秒追加されます。
- 注文は最大3枠。最初の注文は0秒・3.5秒・7秒に始まります。
- 正解した枠では1.3秒後に次の注文が始まります。ほかの枠の進行には影響しません。
- 同時に同じ番号は出さず、直前に注文した番号もその枠には続けて出しません。
- 文字は1文字0.35秒。注文文のあと3.5秒待ってから「注文番号は」を改行して表示し、料理名と番号を太字で強調します。デザートは料理名の前に「すぐに／あとで」を伝えます。
- 数字を4桁入力して「次へ進む」。PCは数字キーとEnterでも操作できます。
- Backspaceまたは「削除」で1文字削除。Deleteまたは「全消去」で入力を消せます。
- 不正解は再入力できます。正解数・正確さ・最大連続正解を結果に表示します。
- メニュー表示中や背景タブでは文字送りを止めますが、制限時間は進みます。
- 時間切れで入力を終了。ブラウザの処理が遅れても、期限以降の注文は加算しません。
- ベストの注文数はブラウザ内に保存します。以前の5品制のスコアとは別に保存します。
- 効果音は右上から切り替えられます。

## 画面

開始ボタンはPCでは左のゲーム欄、スマホでは上部に配置しています。
ゲーム開始後は卓のイラストを非表示にします。
注文パッドはPCでは右下、幅760px以下では画面下にコンパクトに配置します。
スマホでは3つの吹き出しを縦に並べ、読めるスペースを優先します。
吹き出しの文字はPCで24px、スマホでは画面幅と高さに応じて調整します。
UIにはBIZ UDPゴシックなどのゴシック体を指定し、端末で利用できる書体に切り替わります。
外部フォントは読み込みません。

参考写真に合わせた番号欄・数字キー・緑の削除キー・赤い「次へ進む」を使用します。
スマホではメニュー名の表示領域の高さを常に確保するため、数字キーの高さは変わりません。
下部5ボタンはありません。注文外のメニューも登録済みの番号なら品名が表示されます。

## スマホから同じWi-Fiで遊ぶ

PCでプロジェクトフォルダを開いて実行します。

```powershell
python -m http.server 4173 --bind 0.0.0.0
```

PCでは `http://localhost:4173`、スマホでは `http://<PCのローカルIPアドレス>:4173` を開きます。
必要に応じてWindowsファイアウォールでプライベートネットワークへのアクセスを許可します。
Ctrl+Cでサーバーを停止します。

## 構成・テスト

- `index.html`：画面とダイアログ
- `styles.css`：レイアウト、吹き出し、開始画面
- `order-pad.css`：参考写真に合わせた注文パッド
- `game.js`：ゲーム、文字送り、残り時間、番号判定、効果音
- `tests/game.test.cjs`：ブラウザの時計を模擬した動作テスト

```powershell
node --test tests/game.test.cjs
```

番号検索は `MENU_CATALOG`、注文候補は `ORDER_MENUS` で管理します。
追加番号は[公式人気メニュー一覧](https://www.saizeriya.co.jp/menu-popular/)（2026年11月1日確認）、1408は添付の注文画面を参照しました。
全商品を網羅するものではありません。本作は非公式で、実際の注文は送信されません。
外部ライブラリ・アクセス解析・バックエンドは使っていません。
